# X助手（Chrome MV3）

当前版本通过独立的网页版控制台分开运行首页互关贴关注、首页互关贴评论、回复自己帖子下的评论、清理没有回关你的单向关注、回关关注了你但你尚未关注的账号。回复内容由你配置的兼容 OpenAI Chat Completions API 生成。关注列表任务每轮最多处理 20 个账号。

## 安装

1. 在 Chrome 打开 `chrome://extensions` 并开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 点击工具栏中的扩展图标，再点“打开网页版控制台”。控制台可选择当前打开的 X 标签页、配置并启停任务。通过“设置模型 API”或扩展详情中的“扩展程序选项”，填写兼容 OpenAI Chat Completions 格式的 HTTPS API 地址、模型名和 API Key。
4. 重新加载扩展并刷新 X 页面。在控制台选择 X 首页并启动首页任务。互关帖仅通过关键词识别；关注和评论同时启用时先关注再评论。关注列表任务会导航到当前账号的“正在关注”或“关注者”列表。

默认使用 OpenAI API。被选中的帖子文本会发送到你配置的 API 用于生成回复。浏览器扩展本地存储不是密钥保险库，推荐使用自建代理并保护代理访问权限。


## 榜单博主互动

1. 重新加载扩展，打开控制台的“榜单博主互动”，点击“打开榜单选择分类”。
2. 在 xbangdan.com 的账号榜选择赛道、排序、时间、粉丝范围。回到控制台，选中该榜单标签页，设置检查数量后导入。导入先应用控制台自选的榜单类型、排序、时间、赛道和粉丝范围，再从第一页向后翻页，按自定义数量读取，不设置固定 100 人或 10 页上限；达到指定数量、榜单末页、页面重复或加载超时时结束导入，并显示原因。选择“沿用网站当前选择”时保留该组筛选；更改控制台筛选后需重新导入。
3. 设置博主间隔，选择已登录的 X 标签页，点击“开始榜单互动”。任务与原首页任务切换运行。
4. 不再判断博主活跃度、评论数量或互动证据，也不访问博主的回复页。读取主页帖子，按发布时间优先选择最新的可评论、未处理帖子，避免置顶旧帖优先。
5. 评论沿用固定回复/AI 回复设置。固定回复不调用模型；AI 回复仅用模型生成评论。确认发送成功后关注，每位博主只评论一条，已完成账号按当前登录账号去重；发送结果不确定时跳过，不自动重发。

每位博主最多下滑 4 次、收集约 20 条样本，按已加载帖子的实际发布时间排序，不能保证覆盖未加载的内容。没有可评论帖子时跳过。任务进度保存在浏览器本地，刷新后续跑；模型或页面报错等待 30 秒重试，检测到指定关注限速提示时等待 3 分钟，只重试关注。检查完本次导入队列后结束。


### 并行处理榜单博主

“同时处理博主数”可选 1–10，默认 1。启动后保留控制标签页，后台为每路打开独立 X 标签页，将导入的账号去重后分配处理；各路分别保存进度和去重记录，控制台汇总显示。操作间隔按每路计算。任一路检测到指定关注限速提示后共享 3 分钟关注冷却。点击停止会停止所有路并关闭工作标签页；关闭尚未完成的工作标签页也会停止全部任务。全部分配队列处理完后自动结束。

自动评论（首页、自己帖子回复、榜单互动）统一至少间隔 15 秒，榜单并行标签页共享发送间隔。等待期间可停止任务；刷新或后台重启后仍保留发送时间。
