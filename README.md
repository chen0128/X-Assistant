# X助手精简版

免费提供首页互关关注、取消单向关注、回关关注者，以及生成草稿后编辑、复制、手动发送回复。

## 关注解锁功能二

1. 在侧边栏点击“打开博主主页”，自行关注 @灰小王。
2. 返回原 X 标签页，点击“验证关注”。插件打开临时后台主页，仅检查登录账号和关注按钮状态，完成后关闭。
3. 功能二始终显示；未验证时点击会提示先关注并定位到验证按钮。验证成功后可勾选并开始首页任务。与功能一同时启用时先关注再评论。自动评论保持至少 15 秒间隔。

验证绑定操作标签页和当前登录账号。开始自动评论时复核；每次发送检查账号，关注状态最多缓存 5 分钟。缓存仅保存在浏览器会话存储，不能凭本地 UI 状态直接获得发送许可。到期会重新读取主页；已取消关注、账号变化、页面结构不匹配或无法确认时关闭自动评论。仅评论任务停止；同时运行的关注任务可继续。重新启动浏览器后需要重新验证。

这属于客户端功能引导，不是不可破解的授权：开源扩展可被用户修改，DOM 验证也依赖 X 页面结构，不能提供服务端授权的防篡改保证。不使用卡密，不需要卡密服务器。

API 固定为 https://hdwai.eu.cc/v1。浏览器扩展选项中配置该平台的 Key 和支持的模型。安装要求 Chrome 116+；在 chrome://extensions 加载本目录，更新后重新加载并刷新 X。不要同时运行原版和精简版操作同一账号。

免验证白名单：当前登录账号为 @jixu_ai 时，可直接使用功能二；切换账号后按普通关注验证规则执行。此白名单不影响取消单向关注规则。
