# X助手（Chrome MV3）

当前版本通过独立的网页版控制台分开运行首页互关贴关注、首页互关贴评论、回复自己帖子下的评论、清理没有回关你的单向关注、回关关注了你但你尚未关注的账号。回复内容由你配置的兼容 OpenAI Chat Completions API 生成。关注列表任务每轮最多处理 20 个账号。

## 安装

1. 在 Chrome 打开 `chrome://extensions` 并开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 点击工具栏中的扩展图标，再点“打开网页版控制台”。控制台可选择当前打开的 X 标签页、配置并启停任务。通过“设置模型 API”或扩展详情中的“扩展程序选项”，Key 保存在此浏览器的扩展本地存储中。
4. 请注册 heidawang.top，点击 API 密钥创建密钥，选择 OpenAI 创建后使用。注册账户会有初始额度可用。
5. 重新加载扩展并刷新 X 页面。在控制台选择 X 首页并启动首页任务。互关帖识别保留关键词，并可使用 AI 补判未命中的互关 / 交友帖；关注和评论同时启用时先关注再评论。关注列表任务会导航到当前账号的“正在关注”或“关注者”列表。
